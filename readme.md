Avenirs — Définition d’une solution client
Ce dépôt contient l’ensemble des livrables du projet Avenirs, réalisé dans le cadre du parcours Développeur d’application PHP/Symfony (OpenClassrooms).
L’objectif : concevoir une solution claire, structurée et adaptée aux besoins du client, incluant :
un Product Backlog mis à jour,
une veille technologique,
un document de cadrage complet,
une présentation client.

1. Contexte
L’association Avenirs accompagne des adolescents et jeunes adultes en difficulté scolaire en les mettant en relation avec des tuteurs bénévoles.
Le site actuel est peu utilisé → gestion compliquée, perte de temps, manque d’efficacité.
Objectif du projet : proposer une solution web moderne, simple et adaptée au public, basée sur PHP / Symfony.
